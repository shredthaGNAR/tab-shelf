Sync

Uses your Firefox account. Make sure Add-ons is ticked under Settings › Sync on each device. Firefox Sync gives extensions about 100 KB, which holds roughly 600 to 1,500 tabs. If you save more, the most recently changed ones sync and the rest stay safe on this device. Favicons are not synced.

AI tagging

Tabs are tagged by an OpenAI-compatible chat API using your own key. Only each tab's title and URL are sent. The key is stored on this device only. It is never synced or exported.

Appearance & shortcuts

Default shortcuts: Alt+Shift+S save tab, Alt+Shift+W save window, Alt+Shift+M manager, Alt+Shift+T popup. Change them in about:addons › ⚙ › Manage Extension Shortcuts.
